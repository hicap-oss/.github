# .github

This is the default community health files repository for the Hicap OSS organization.

## Contents

- **profile/README.md** - Organization profile displayed on github.com/hicap-oss
- **CODE_OF_CONDUCT.md** - Community guidelines
- **CONTRIBUTING.md** - Contribution guidelines
- **SECURITY.md** - Security policy
- **SUPPORT.md** - Support information
- **.github/ISSUE_TEMPLATE/** - Issue templates
- **.github/PULL_REQUEST_TEMPLATE.md** - Pull request template
- **workflow-templates/** - Reusable workflow templates

These files are automatically applied to all Hicap repositories that don't have their own versions.
